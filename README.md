# wordfindコマンド

![test](https://github.com/MasaharuWatanabe1/robosys2026task1/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ文章の中から、指定した文字列を含む行を検索し、その行番号を標準出力に表示するコマンドです。

## 使用方法

検索したい文字列を引数に指定し、テキストファイルの内容を標準入力から読み込んで実行します。

### ① テキストファイルを用意する

検索対象となる sample.txt を作成します。

```
$ nano sample.txt
```

例えば、以下の文章を入力して保存します。

```
今日はドライブに行った
最近ハマってるんだよね
ドライブは楽しい
特にPA巡りが好き
```

### ② テキストファイルから検索する

「ドライブ」という文字列を検索します。

```
$ cat sample.txt | ./wordfind ドライブ
1
3
```

上記の例では、sample.txt の中から「ドライブ」を含む行を検索し、該当する行番号のみを表示します。

## 必要なソフトウェア

- Python
  - テスト済みバージョン: 3.10〜3.14

## テスト環境

- Ubuntu 24.04 LTS
